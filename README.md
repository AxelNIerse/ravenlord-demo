# Ravenlord: The Broken Gate

A hand-drawn 2D tower-defense demo for Windows. Defend Vaelrik, collect dungeon creatures, choose spells and reclaim six dungeon chambers.

## Download and play

**[Download the Windows demo v0.11](https://github.com/AxelNIerse/ravenlord-demo/releases/download/v0.11/Ravenlord-The-Broken-Gate-v0.11-Windows.zip)** (about 89 MB).

1. Download the ZIP above.
2. Extract the entire ZIP into a folder.
3. Open **Ravenlord.exe** in that folder. Keep the other extracted files alongside it.

Unity, GitHub Desktop and GitKraken are not required. Choose the Windows ZIP under **Assets** on the [release page](https://github.com/AxelNIerse/ravenlord-demo/releases/tag/v0.11), rather than GitHub’s automatically generated source-code archives.

New players start with zero cleared rooms. Progress saves locally on your PC; existing players retain their own previous progress.

## Controls

- Left-click a summon spot to place a creature; select it to upgrade or specialize.
- Q / W / E selects a spell; left-click casts; Escape cancels targeting.
- Space starts a wave or pauses/resumes. Escape opens the pause menu.
- Wave info shows enemy counts and traits; Show route reveals direction arrows.
- Settings, restart, return to map and feedback details are available while paused.

The sanctuary is the end of this demo. Optional rooms unlock a creature and equipment. No tutorial is included; an optional Controls reference is available.

## Feedback

Use the included FEEDBACK.txt or open an issue here. Include the room, wave, spell/creature choices, placement screenshot and what happened. Pause > Feedback / log location gives your log path and a copyable report template. Nothing is uploaded automatically.

This repository hosts demo downloads and instructions. The Unity development project is not included. Audio credits and provenance are included in the ZIP’s Licenses folder.
